[2026-11-17] · The latest from GitHub's engineering team - The GitHub Blog
GitHub 工程團隊說明他們如何打造開放的 Agent Host Protocol，讓 AI 代理的工作階段（session）可以在不同編輯器、App、手機與雲端之間無縫延續，而不是像現在多數工具一樣各自孤立。這解決了目前 AI 編碼代理普遍存在的痛點：換裝置或換介面就等於重新開始一段對話，使用者得重新交代上下文。

  • 新在哪：Agent Host Protocol 把「代理工作階段」抽象成可攜的開放協定，讓不同主機（host）都能接續同一個 session
  • 解決了什麼：使用者可以在手機上開始、在桌機編輯器裡接續同一個 AI 代理任務，不必重複描述需求
