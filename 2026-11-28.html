4.【The Cloudflare Blog】Introducing Search for Agents
[2026-11-25] · The Cloudflare Blog
Cloudflare 推出「Search for Agents」，網站只需打開一個開關，就能自動為站內內容建立索引、提供可被發現的搜尋 API，並原生支援 HTTP QUERY 方法，讓 AI 代理能以結構化方式查詢網站內容，而不必再靠傳統網頁爬蟲硬解析 HTML。
新舊比較：
  • 先前：過去網站若想讓 AI 代理存取內容，通常只能被動地被爬蟲擷取整頁 HTML，沒有專門給代理用的搜尋介面。
  • 新在哪：Cloudflare 讓站主一鍵開啟自動內容索引、對外提供可被發現的搜尋 API，並支援原生的 HTTP QUERY 方法。
  • 解決了什麼：網站不必額外開發或維運搜尋基礎設施，就能讓 AI 代理以結構化、可控的方式查詢內容，降低被暴力爬取的負擔並提升代理取得資訊的準確度。

8.【Changelog】Warp bets on the software factory
[2026-11-24] · Changelog

  • 解決了什麼：讓 AI 代理能更深入接管從寫程式到審查、部署的完整流程，資深工程師的角色也從守門人轉為使用者，理論上可大幅提升交付速度。

10.【OMG! Ubuntu!】Claude artifacts can now be installed as desktop apps (just not on Linux)
[2026-11-25] · OMG! Ubuntu!
Anthropic 新增功能，讓 Claude 聊天中生成的 artifacts（LLM 即時產生的小型互動工具）可透過「Install as app」安裝成獨立桌面應用，擁有自己的視窗與圖示，還能發送桌面通知、註冊鍵盤快捷鍵並加入系統面板；若授予完整系統權限，甚至能讀寫與刪除檔案。此功能目前為 Beta，已開放給 Windows 與 macOS 上所有方案（含免費版）的使用者，但 Linux 版 Claude 桌面應用暫未支援。
新舊比較：
  • 先前：過去 Claude 的 artifacts 只能在網頁聊天介面裡暫時存在，關掉分頁就消失，沒有獨立視窗或系統層級的整合。
  • 新在哪：Artifacts 現在可以一鍵安裝成有自己視窗、圖示、通知與鍵盤快捷鍵的獨立桌面應用，並可選擇授予完整系統權限。
  • 解決了什麼：讓原本一次性、用完即丟的聊天小工具，不必額外打包發布流程，就能變成可長期留存、與作業系統深度整合的常駐小應用程式。
評語：把今天的幾則新聞放在一起看，會發現一個頗諷刺的對照：同一天，WebRTC 側錄腳本被抓到利用一條少被監控的通訊管道竊取信用卡資料，Convex 的 AI coding skill 被抓到在使用者不知情下把 app 構想傳回自家伺服器，而 Cloudflare 卻正忙著幫網站鋪一條讓 AI 代理「正當」查詢內容的高速公路——建立代理可信存取管道的速度，幾乎與濫用代理／規避偵測的速度一樣快，兩者用的其實是同一種技術邏輯：讓程式之間用非傳統管道互相「說話」。另一個值得留意的細節，是 djb 整理的「電腦驗證過卻是錯的證明」：它提醒我們形式化驗證並非萬無一失的保證，機器檢查的可信度終究取決於規格與驗證器本身有沒有錯，這和「AI 代理寫的程式碼到底能不能信任」是同一個問題的不同版本。放在這個脈絡下，Warp 把 CI/CD 重新定義成由代理驅動的「軟體工廠」、Discord 把錄製精彩瞬間的決定權交給系統自動判斷，都呼應著同一個趨勢：越來越多原本需要人把關、人核可的環節，正在被悄悄交給自動化系統決定，而今天這幾則新聞剛好同時展示了這種信任轉移帶來的機會與代價。
