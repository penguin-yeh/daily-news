1.Anthropic 推出 Claude for Manufacturing：一個 plugin 裝 17 個 skill＋4 個 connector
AI 報 · 主軸 / Anthropic / Claude / agent
Anthropic 11/12 推出 Claude for Manufacturing：一個 plugin 裡裝了 17 個 skill（可想成寫成檔案、AI 照著做的 SOP）和 4 個 connector（Autodesk Fusion、Infor、Microsoft 365、Oracle NetSuite），涵蓋報價、品質調查、生產報表、故障診斷、採購與設計比較。例如品質工程師處理一次檢驗不合格：記錄失效、翻過去同類報告、排出可能原因、draft 矯正措施報告，並綁好要讀哪個系統、最後由誰放行；故障診斷 skill 會讀感測匯出、維修紀錄、照片與手冊，排出可能原因交給技術員確認。安裝後對 Claude 說一句「Set us up」，它會先測試 connector，回報哪些 skill 還跑不完整。治理面：官方明說不操作設備、不寫入記錄系統（System of Record），在 Infor 的權限跟著使用者走，要改單得另裝 Infor 自家 plugin 並經採購核准。限制：只具名 6 個 skill、沒有客戶案例或效益數字；connector 以 ERP 與設計工具為主，MES、良率系統等不在清單，沒 connector 的系統得靠定期匯出到 Microsoft 365。編輯分析：這是用「唯讀＋draft＋人簽核」換企業 IT 點頭，先拿文書工作立功，再談碰到真正的系統。
